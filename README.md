# 🪐 BlockTextQ

* **Name:** BlockTextQ
* **Author:** Klaxons, noname

### Summary

Disables the issuance of text quests as government missions

---

## 📖 Description

Completely disables the issuance of text quests as government missions. The Prison quest, as well as the quests necessary for the pirate plot, will not be disabled.
